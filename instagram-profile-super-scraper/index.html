What does Instagram Profile Scraper do?

Instagram Profile Scraper returns public profile data for any list of Instagram usernames or profile URLs, without an Instagram login. For each profile you get the user ID, username, full name, biography, exact follower and following counts, post count, bio links, external website, verified and private flags, profile picture, the latest 12 posts with captions, hashtags and image URLs, and up to about 50 related profiles that Instagram suggests next to the account. It reads the same data Instagram shows to logged-out visitors through rotating residential proxies, retries on a new IP when a request is blocked, and only pushes profiles that loaded completely, so you never pay for empty rows. Unknown usernames are skipped and listed with the reason. Results export to JSON, CSV or Excel, or come back through the Apify API and MCP server. It is built for influencer discovery, lead lists, competitor tracking and audience research at scale.

FAQ

Do I need an Instagram account or cookies?

No. Follower and following counts, bio, links and latest posts all come back without a login. Cookies from your own secondary account are optional.

Are follower counts exact?

Yes. followersCount and followsCount are exact. postsCount is rounded the way Instagram shows it to visitors, for example 32000 for 32K posts.

Why are likes and comments empty in latestPosts?

The logged-out profile grid does not include them. Run the Instagram Post Scraper on the profile to get engagement per post.

Can I find similar accounts?

Yes. relatedProfiles lists the accounts Instagram suggests next to the profile, which is useful for influencer discovery.

What am I charged for?

Each profile pushed to the dataset is one result. Unknown, private or failed profiles are not charged. See the Pricing tab for the current price.

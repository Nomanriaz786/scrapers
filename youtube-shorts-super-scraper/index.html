What does YouTube Shorts Scraper do?

YouTube Shorts Scraper collects the public Shorts of one or more YouTube channels without the YouTube Data API and its quotas. You give it channel handles such as nasa or @nasa, or channel URLs such as https://www.youtube.com/@vsauce, and it returns one dataset row per Short. Each row has the Short's title, video ID, URL, thumbnail, view count, like count, publish date, duration, description and hashtags. Every row also carries the channel's name, ID, handle, subscriber count, total views, video count, join date, description links, avatar, banner and verified status. You choose how many Shorts to take per channel and which list to read: YouTube's Latest, Popular or Oldest view of the Shorts tab. An optional date filter keeps only Shorts published after a given day. Results can be downloaded as JSON, CSV, Excel or HTML, or read through the Apify API. It suits content research, competitor tracking and trend analysis.

FAQ

Do I need a YouTube API key?

No. The Actor reads the public YouTube pages a logged out visitor sees, so there is no API key and no daily quota.

Which channel inputs are accepted?

Handles with or without @, and https URLs on youtube.com, www.youtube.com or m.youtube.com that point at a channel. Video URLs, other websites and plain http links are skipped, so the Actor never fetches an address you did not mean to give it.

How many Shorts can I get from one channel?

As many as YouTube lists on the channel's Shorts tab, up to your maxResultsShorts. The Actor follows YouTube's "load more" pages, so Vsauce returned 60 of 60 requested in testing. Some channels show a shorter list with no further pages: NASA's Latest list stopped at 41 Shorts in testing.

How do the sort options work?

They pick YouTube's own Latest, Popular or Oldest view of the Shorts tab, so POPULAR returns the channel's most viewed Shorts, not just the newest ones sorted by views.

What happens if YouTube blocks or rate limits the run?

A request that gets HTTP 429 or a bot check is retried on a new proxy session with a growing pause, up to maxRequestRetries times. If a Short's details still cannot be loaded, it is saved with what the Shorts grid shows (ID, URL, title and a rounded view count) and listed in the FAILED_ITEMS record of the run's key-value store. A channel whose Shorts tab cannot be loaded is listed there too, and the other channels still run.

Should I use a proxy?

Yes. The default is Apify residential proxy, because YouTube often answers datacenter IPs with HTTP 429. A direct connection from a home IP can work for small runs.

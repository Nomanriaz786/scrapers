What does Pinterest Scraper do?

Pinterest Scraper extracts public data from Pinterest without a login or account cookies. Give it search keywords, pin URLs, board URLs or profile URLs, and it returns one clean item per pin with the title, description, alt text, outbound link and domain, the full-size image plus 736x and 474x versions, the video URL for video pins, the creation date, save, repin, reaction and comment counts where Pinterest shows them, the dominant color, the board and the pinner. For profile URLs it also returns one profile item with the follower, following, pin and board counts, monthly views, bio, website and verified flags. It reads the same JSON that Pinterest's own website loads for logged-out visitors, so runs are light and fast, and pins found by two inputs in one run are returned and charged once. Use it for trend research, mood boards, competitor and creator analysis, ecommerce product discovery and image datasets.

FAQ

Do I need a Pinterest account?

No. The scraper never logs in and never uses account cookies. It reads the public data Pinterest serves to any logged-out visitor. It does not solve captchas or get around login walls, so anything Pinterest only shows to signed-in users is not returned.

How many pins can I get from a search?

Up to maxItemsPerInput per query. Results are loaded 25 pins at a time until your limit is reached or Pinterest stops serving more. Pinterest limits what logged-out visitors see, and from some IP addresses and countries it returns no search results at all. A search that returns nothing is retried on a new proxy IP, and if it still returns nothing it is listed in FAILED_ITEMS and not charged.

Can I download images and videos?

Yes. Every pin has imageUrl (the largest version, usually the original upload) and images with the original, 736x and 474x links. Video pins have videoUrl, the widest MP4 when there is one, otherwise an HLS (.m3u8) playlist. The actor returns links only; download the files with any tool you like.

Why are some counts missing?

Pinterest sends different fields on different pages. Board pins include saves and repins but no creation date. Profile pins include the creation date and reactions but no saves. Pin URLs return the most complete data, including comments. A field Pinterest did not send is null instead of a guessed zero.

What does YouTube Search Scraper do?

YouTube Search Scraper turns any YouTube search into a clean dataset with one record per video result, in the order YouTube ranks them. Type one or more search queries and choose how many results you want per query; the scraper keeps loading the next results pages until it reaches that number or YouTube runs out. Each record has the video ID, URL, title, channel name, channel ID and channel URL, view count as a number, published time, duration in seconds and as text, thumbnail, description snippet, badges such as 4K or CC, live and Shorts flags, the query and the rank. You can narrow results with YouTube's own upload date, duration and feature filters, sort by popularity, and pick the country and language YouTube ranks for. It needs no YouTube API key, no login and no cookies, which makes it a simple tool for keyword research, rank tracking and content discovery.

FAQ

Do I need a YouTube API key?

No. The scraper reads the same public search results a logged-out visitor sees, so there is no API quota and nothing to log in to.

Can I get more than the first page of results?

Yes. YouTube shows about 20 results per page. The scraper follows YouTube's continuation pages until it has Max results per query videos or YouTube has no more results.

Which filters are supported?

Upload date (last hour, today, this week, this month, this year), duration (under 4 minutes, 4 to 20 minutes, over 20 minutes) and the features Live, 4K, Subtitles/CC, 360 degrees and VR180. Filters can be combined. Each one was checked against live YouTube results before it was added.

Is sorting by view count exact?

No. YouTube's popularity order puts the most viewed videos first but is not strictly sorted by views. Sort the dataset by viewCount yourself if you need a strict order.

Are playlists and channels in the results included?

No. Only video results are returned. Playlists, mixes, channel cards, ads and shelves such as "People also watched" are skipped, and rank counts videos only.

What happens when a page fails?

Each results page is retried on a fresh proxy IP up to Max request retries times. Videos already collected for the query are kept. Queries that stop early or return nothing are listed in the FAILED_ITEMS record of the run's key-value store.

What does YouTube Scraper do?

YouTube Scraper collects public video data from YouTube without the YouTube Data API and its quotas. You give it search terms, channel URLs or video URLs, and it returns one dataset row per video. Each row has the video title, ID, URL, thumbnail, view count, like count, comment count, upload date, duration, description, hashtags and links found in the description. Every row also carries the channel's name, ID, handle, subscriber count, total views, video count, join date, avatar, banner and verified status. From a channel URL it can read the Videos tab, the Shorts tab and the Live tab, each with its own limit. Search results can be narrowed with YouTube's own filters, such as upload date, length, HD, 4K, live or Creative Commons. Results can be downloaded as JSON, CSV, Excel or HTML, or read through the Apify API. It suits content research, competitor tracking and building video lists for analysis.

FAQ

Can I scrape a whole YouTube channel?

Yes, up to your limits. Paste the channel URL and set Maximum videos to the number of videos you want. The scraper pages through the Videos tab until it reaches that number or the end of the channel. Shorts and live streams have their own limits.

Does it need a YouTube API key?

No. It reads the same public pages a browser loads, so there is no API key and no daily quota.

Can it scrape YouTube comments or transcripts?

No. It returns the comment count only. For comment text use YouTube Comments Scraper. For transcripts and subtitles use YouTube Video Transcript Scraper.

Can I combine search filters?

Yes. Upload date, type, length and the feature filters are sent to YouTube together as one filter set.

Do I need a proxy?

Small runs often work without one. For larger runs on the Apify platform, turn on Apify Proxy so YouTube is less likely to block or rate limit the run.

Is it legal to scrape YouTube?

The scraper only reads publicly visible data. You are responsible for how you use it, including YouTube's terms and privacy laws such as the GDPR when data relates to people.
